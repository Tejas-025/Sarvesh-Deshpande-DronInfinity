TandemWingVTOL_UAV

A MATLAB project for conceptual aircraft design and analysis of a Tandem Wing VTOL UAV.

Scripts:
- main.m: Main execution script that runs all analyses.
- parameters.m: Defines all UAV parameters.
- aircraftSizing.m: Calculates wing loading and aspect ratio.
- aerodynamicAnalysis.m: Calculates lift, drag, and aerodynamic coefficients.
- hoverPower.m: Estimates hover power required.
- cruisePower.m: Estimates cruise power required.
- batterySizing.m: Calculates battery energy and capacity requirements.
- weightBreakdown.m: Provides a component weight breakdown.
- cgCalculation.m: Estimates the center of gravity.
- missionProfile.m: Plots the mission power profile.
- performancePlots.m: Plots power required vs. velocity.
- enduranceValidation.m: Validates endurance based on battery capacity.
- stabilityAnalysis.m: Estimates static margin for longitudinal stability.

Usage:
Run `main.m` in MATLAB or Octave to execute the full suite of analyses.
